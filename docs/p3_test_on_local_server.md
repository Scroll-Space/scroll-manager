# 3. Тестирование на локальном сервере onlyoffice

## 3.1 Запуск локального сервера
В корне проекта выполните комманду
```bash
docker compose up -d --build
```
> [!NOTE]
> Эту же команду можно использовать для перезапуска сервера после изменений в плагине. Предварительно выполнять `docker compose down` не требуется — Docker сам пересоберёт образ и пересоздаст контейнер.
## 3.2 Открытие pdf файла
1. Откройте onlyoffice в [браузере](http://localhost/example/).
2. Загрузите любой PDF файл на ваше усмотрение.
3. Тестируйте работу плагина.

## 3.3 Остановка сервера
```bash
docker compose down
```
