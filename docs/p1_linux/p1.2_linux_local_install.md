# 1.2 Локальная установка плагина в linux

## 1.2.1 Удаление старого каталога плагина
```bash
rm -rf ~/.local/share/onlyoffice/desktopeditors/sdkjs-plugins/{CA39B178-83EF-4074-B248-108D0634A4DB}
```

## 1.2.2 Создание целевого каталога в директории с плагинами
```bash
mkdir -p ~/.local/share/onlyoffice/desktopeditors/sdkjs-plugins/{CA39B178-83EF-4074-B248-108D0634A4DB}
```

## 1.2.3 Копирование всех файлов в целевой каталог плагина
```bash
cp -r ./src/ ~/.local/share/onlyoffice/desktopeditors/sdkjs-plugins/{CA39B178-83EF-4074-B248-108D0634A4DB}/
```
