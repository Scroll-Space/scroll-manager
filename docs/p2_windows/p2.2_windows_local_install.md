# 3.2 Локальная установка плагина в windows

## 3.2.1 Удаление старого каталога плагина
```powershell
Remove-Item -Path "$env:LOCALAPPDATA\ONLYOFFICE\DesktopEditors\data\sdkjs-plugins\{CA39B178-83EF-4074-B248-108D0634A4DB}" -Recurse -Force
```

## 3.2.2 Копирование всех файлов в целевой каталог плагина
```powershell
Copy-Item -Path ".\src" -Destination "$env:LOCALAPPDATA\ONLYOFFICE\DesktopEditors\data\sdkjs-plugins\{CA39B178-83EF-4074-B248-108D0634A4DB}" -Recurse
```
